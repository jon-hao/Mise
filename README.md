# Mise

清新家常菜谱应用：按菜名、食材与多维标签快速找到做法。

**在线地址：** https://jon-hao.github.io/Mise/

## 能怎么搜

| 维度 | 说明 | 例子 |
| --- | --- | --- |
| 菜名 | 顶部搜索，模糊 + 俗称 | 土豆丝、番茄炒蛋、宫爆鸡丁 |
| 食材 | 筛选弹窗内多选 | 土豆 + 猪肉；马铃薯=土豆 |
| 分类 | 家常 / 主食 / 汤煲 / 素菜… | 面点包子、海鲜 |
| 做法 | 炒、炖焖、蒸、煮汤… | 快手炒菜 |
| 口味 | 酸辣、酱香、番茄味… | 麻辣、清淡 |
| 用时 | 滑块限制上限 | ≤15 分钟 / ≤30 分钟 |

主界面突出菜谱列表；支持双列卡片与单列列表切换。

## 本地预览

```bash
# 任意静态服务器即可，例如：
python3 -m http.server 5173
# 打开 http://localhost:5173
```

## 数据

- 原始菜谱文本：`_recipes_raw.txt`
- 结构化数据：`data/recipes.json`（103 道）

## 设计参考

参考下厨房 / BBC Good Food 等：顶部强搜索、食材多选 chips、分组筛选、结果计数与可点卡片详情。视觉走清新绿意 + 珊瑚点缀，适合美食教程气质。
